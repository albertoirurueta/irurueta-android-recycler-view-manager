== Requirements

* Android `minSdk` 26 (Android 8.0) or later.
* The library is compiled against SDK 37, with Java/Kotlin JVM target 17.
* Its `hermes` dependency (1.3.1 and later) is compiled for Java 21. That is fine on devices, but JVM unit tests in your
  app that load hermes classes need to run on JDK 21 or later.
* Your project must already use `androidx.recyclerview` (it is the widget the library drives).

== Gradle (Kotlin DSL)

Make sure `mavenCentral()` is among your repositories (in `settings.gradle.kts`):

[source,kotlin]
----
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
    }
}
----

Then add the dependency to your module's `build.gradle.kts`:

[source,kotlin]
----
dependencies {
    implementation("com.irurueta:irurueta-android-recycler-view-manager:1.1.5")
}
----

== Transitive dependencies

The library exposes https://github.com/albertoirurueta/hermes[`com.irurueta:hermes`] as an `api` dependency. The
comparator interfaces (`com.irurueta.hermes.ItemComparator` and `com.irurueta.hermes.ItemContentComparator`) and the
change classes returned by the detector are therefore available on your compile classpath without declaring hermes
yourself.
