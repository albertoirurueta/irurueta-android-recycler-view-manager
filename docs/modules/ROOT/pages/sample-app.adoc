shows `RecyclerViewManager` animating list updates.

image::recycler-view-manager.gif[Sample app animating list updates,width=300]

== What it does

The single screen (`MainActivity`) shows a `RecyclerView` and a *Change* button. Each tap generates a random list of
up to 10 `Item(id, name)` entries:

* the number of items changes, which produces insertions and removals;
* the order is randomly reversed, which produces moves; and
* some names get a trailing `*`, which produces content updates for items whose `id` is unchanged.

The manager turns each new list into the matching notifications, so every kind of animation can be seen.

And the button handler follows the two-step update described in xref:usage.adoc#_4_notify_changes[Usage]:

[source,kotlin]
----
private fun updateItems() {
    val oldItems = adapter.items
    val newItems = generateItems()

    // update the adapter with the new items before notifying the adapter
    adapter.items = newItems
    // compute changes and notify the adapter
    manager.notifyChanges(oldItems, newItems)
}
----
